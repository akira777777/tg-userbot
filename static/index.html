Действия для выбранного аккаунта

Рассылка в группы (broadcast)

DM участникам (dmsend)

кросс-аккаунтная дедупликация: кому писал ЛЮБОЙ аккаунт — не повторит никто; дневной бюджет на аккаунт

🎼 Дирижёр — одна кампания на весь организм

цели делятся между всеми включёнными аккаунтами; FloodWait одного — цель сразу подхватывает другой; DM-бюджеты на аккаунт; groups — только теми, кто в них состоит
