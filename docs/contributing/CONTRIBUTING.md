# Contributing

> Гайдлайн для вкладчиков tg-userbot.

## Быстрый старт

```bash
# Клонируй репозиторий
git clone https://github.com/novra/tg-userbot.git
cd tg-userbot

# Создай виртуальное окружение
python -m venv .venv
source .venv/bin/activate  # или .venv\Scripts\activate на Windows

# Установи зависимости
pip install -e ".[dev]"

# Запусти отладочный сервер
make dev
```

## Структура проекта

```
tg-userbot/
├── src/tg_userbot/
│   ├── app/          # конфигурация, логирование, middleware
│   ├── handlers/     # обработчики команд
│   ├── media/        # медиа-библиотека
│   ├── database/     # интеграция с Supabase
│   ├── telegram/     # клиенты
│   └── api/          # HTTP API
├── tests/            # тесты
├── scripts/          # утилиты
├── docs/             # документация
└── dashboard/        # React-панель
```

## Стиль кода

### Форматирование

```bash
black src/ tests/
ruff format src/ tests/
```

### Линтинг

```bash
ruff check src/ tests/
```

### Типизация

```bash
mypy src/
```

## Коммиты

Используй [Conventional Commits](https://www.conventionalcommits.org/):

```
feat: новая фича
fix: исправление бага
docs: документация
refactor: рефакторинг без изменения поведения
test: тесты
chore: рутина
```

## Pull Request

1. Создай ветку от `develop`
2. Напиши код + тесты
3. Запусти CI: `make test` + `make lint`
4. Открой PR
5. Жди review + merge

## Code Review

- Минимум 1 ревьюер
- Код покрыт тестами (coverage ≥ 80%)
- Нет новых warnings в линтинге
- Нет regressions в существующих тестах

## Правила

- **Не** вноси изменения в `docs/` без необходимости
- **Не** меняй публичный API без обсуждения
- **Не** используй хардкод (используй константы)
- **Не** забывай `py.typed` в `__init__.py`

## Вклад в документацию

- Пиши чёткие примеры
- Добавляй типизацию в сигнатуры
- Исправляй устаревшие примеры

## Вклад в тесты

- Пиши unit-тесты (pytest)
- Пиши интеграционные тесты (если нужно)
- Не снижай coverage ниже 80%

## Вклад в код

- Пиши модульный код (одна функция = одна задача)
- Используй type hints + pydantic
- Пиши docstring в формате Google-style
- Добавляй type stubs для внешних библиотек

## Вклад в инфраструктуру
