# Медиа-библиотека

Библиотека лежит поверх **«Избранного»** Telegram: файл загружается в Saved Messages
аккаунта, а в SQLite появляется запись. Локальный кэш `media_cache/` (путь меняется
через `USERBOT_MEDIA`) нужен для быстрой раздачи в веб-плеер и Mini App.

## Как это устроено

```text
файл -> client.send_file("me") -> Saved Messages (msg_id)
     -> media_cache/lib_<msg_id>_<name>
     -> SQLite media(id, account, msg_id, kind, title, mime, size, path, added_at)
```

- `account` — чьё «Избранное» хранит файл; одна и та же запись не переносится между аккаунтами.
- `msg_id` — id сообщения в Saved Messages, по нему работает `sync`.
- `path` — локальный кэш; если файла нет, `media list` показывает `✗нет файла→sync`.
- `title`, `mime`, `size` — для списка, подписи и ограничения размера.

## Команды

```bash
python bot.py media add <файл> [--account main]
python bot.py media pull [--limit 30] [--account main]
python bot.py media sync <id> [--account main]
python bot.py media del <id>
python bot.py media list
```

| Команда | Что делает |
| --- | --- |
| `add` | Загружает файл в «Избранное» аккаунта и копирует его в `media_cache`. |
| `pull` | Просматривает последние `--limit` сообщений Saved Messages и добавляет новые фото/видео/документы. |
| `sync` | Перекачивает файл записи из «Избранного» в кэш (например, после очистки `media_cache`). |
| `del` | Удаляет запись из SQLite; файл в кэше и сообщение в Telegram остаются. |
| `list` | Показывает `#id`, тип, название, размер, аккаунт/msg и наличие файла. |

`pull` берёт только медиа с `mime_type`; стикеры, голосовые и прочие служебные
сообщения пропускаются.

## Где используется

- `bot.py broadcast --media <id>` и `bot.py dmsend --media <id>` — отправка вложения
  с подписью; текст длиннее 1024 символов обрезается (`CAPTION_LIMIT`).
- `bot.py conduct --media <id>` — то же в кампании на все аккаунты.
- `web.py`: `GET /api/media/{id}/file` раздаёт файл с поддержкой `Range`
  (веб-плеер), `POST /api/media/upload` принимает файл с машины оператора.
- Mini App: команда `MEDIA_LIST` показывает доступные вложения, `BROADCAST`/`DMSEND`
  принимают `media_id`.

## Ограничения и гигиена

- Лимиты Telegram: подпись к медиа — 1024 символа; размер файла зависит от типа
  аккаунта. Для больших файлов используйте документ, а не видео.
- `del` не удаляет ни кэш, ни сообщение в Telegram — сначала убедитесь, что запись
  больше не нужна кампаниям.
- `media_cache` можно очищать: записи останутся, а `sync` восстановит файл.
- Не храните в кэше чужие персональные данные дольше, чем нужно для кампании.
