# Оформление аккаунтов (оркестр)

Сюда кладутся материалы для `bot.py profile apply`:

- `profiles.csv` — по строке на аккаунт в порядке `python bot.py accounts list`
  (main, work2 … work11). Формат: `Имя; Фамилия; О себе`, лимиты Telegram 64/64/70 символов.
- `avatars/` — картинки `*.jpg`, `*.png`, `*.webp` до 5 МБ, по одной на аккаунт
  в алфавитном порядке; раздаются по порядку аккаунтов.

Проверка без отправки: `python bot.py profile apply --dry-run`.
Состояние применения: `profiles.json` в корне проекта (не в git).
