# Ручные smoke-проверки

Эти скрипты не собираются pytest: им нужна работающая панель или живой аккаунт.
Запускать осознанно, с dry-run и малыми лимитами.

| Скрипт | Что нужно | Что проверяет |
| --- | --- | --- |
| `panel_smoke.py` | `web.py` на `127.0.0.1:8642` | `/api/run` для `conduct`, коды ошибок, состояние задач |
| `media_smoke.py` | `web.py` + авторизованный аккаунт | add/list/Range-раздача/del медиа |
| `probe_mailing_dry_run.py` | ничего, только Python | `send_run` в dry-run не подключается к Telegram |

Проверки без сети и без боевых файлов живут в `tests/`.
